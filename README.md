# PFinance — щоденний облік фінансів

Мобільний застосунок для щоденного внесення витрат і доходів (за зразком Money Manager)
у візуальному стилі дашборда PF. Записи вивантажуються в Excel, який PF імпортує напряму.
Flutter: спершу веб-версія, той самий код пізніше збирається для iOS та Android.

## Що вже є (v0.7)

- Записи: вкладки День / Календар / Місяць / Підсумок, доходи, витрати, перекази (і між валютами), пошук, свайп для видалення з поверненням.
- Додавання: категорії й підкатегорії, підказки нотаток, «Продовжити» для серії записів, дата й час.
- Статистика: діаграма за категоріями з розбивкою на підкатегорії, тренд за 6 періодів, бюджети з позначкою «сьогодні».
- Рахунки: групи (готівка, картки, банк…), чистий капітал, активи й пасиви, виписка по рахунку.
- Налаштування як у Money Manager: початок місяця й тижня, стартовий екран, кольори доходу/витрат, копійки, PIN-код, основна валюта й курси, теми PF (Аврора, Лагуна, Туманність, Захід, Ліс).
- Дані: локально (IndexedDB у браузері), експорт в Excel для PF, резервна копія JSON і відновлення.

## Структура

```
lib/
  data/      модель (models.dart) і локальне сховище sembast (repository.dart)
  state/     AppStore — стан застосунку, підрахунки балансів і підсумків
  ui/        екрани, теми, спільні віджети
test/        модульні тести моделі та сховища
```

Кожен запис має `id` (UUID v7), `updatedAt` і `deleted` (м'яке видалення), щоб пізніше
додати синхронізацію між пристроями. Суми зберігаються цілими числами в копійках/центах.

## Запуск

```bash
flutter pub get
flutter run -d chrome
flutter test
flutter build web --release --no-web-resources-cdn
```

Пуш у `main` автоматично збирає й публікує веб-версію на GitHub Pages
(`.github/workflows/deploy-web.yml`; у налаштуваннях репозиторію Pages → Source: GitHub Actions).
